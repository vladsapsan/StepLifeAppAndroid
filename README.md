# StepLifeApp
Мобильное приложение StepLife на Android c использованием FIreBase

Краткая информация о продвижении разработки

Плановые функции:
-Добавить возможность подключения телефона через блютуз к коленному модулю
-Добавить проверку подключения к интернету.
-Темная и светлая тема.
-Добавить возможность сотрудникам выбирать статьи на главной странице.
-Динамическая подборка статей на главном экране и в учебнике.(Выбор сотрудников)
-Реверсивность языков.
-Рефакторинг кода.
